怎麼合作

  1. 聊你用自己的話講，不用懂技術。我會問「這個東西誰在用、什麼時候用、最怕什麼出錯」。
  2. 畫把聊到的東西畫成概念圖跟需求筆記。你看到畫面，才知道自己真正要什麼。這時候改，最便宜。
  3. 做確認範圍、報價、開工。需要時會有可以點的版本讓你邊看邊給意見，不會做完才發現不對。
  4. 交依案子範圍，先給上鎖的試用版確認，付清後拿原始檔、說明文件、安全檢查報告。之後要改，再聊。

依案子範圍，通常會拿到

  • 需求筆記聊完整理成文字，範圍寫清楚，之後驗收照這份對。
  • 試用版付尾款前先完整試用，確認功能沒問題。
  • 原始碼付清後完整交付，含版本紀錄，換人接手也看得懂。
  • 說明文件怎麼用、怎麼改、怎麼重新上線，白話寫。
  • 安全檢查報告有沒有把密碼直接寫在程式裡、可疑連線、太舊的元件，掃過才交。
  • 進度可見開發中就有可以點的版本，不會做完才發現不對。

價格，另談。

沒有價目表，因為沒有兩個案子是一樣的。把需求講清楚，我會給你一個範圍、一個時程，然後一起把它壓到合理。

  • 範圍要幾個畫面、接不接後端、有沒有登入。範圍越清楚，價格越準。
  • 時間急件可以，但會影響價格。不急的話我會排在品質優先的節奏。
  • 之後做完要不要維護、要不要教你自己改。這些都先講。
用 LINE 問我

找外包前該問的問題，我先答

做好之後，程式是誰的？

付清後原始碼完整交給你，含說明文件。你要自己改、找別人維護、搬到別的主機都可以。

怎麼付款？會不會付了錢拿不到東西？

可以分階段付款。做完先給你一個上鎖的試用版，完整操作確認沒問題，再付尾款、拿原始碼。

交付後壞了、想改怎麼辦？

交付後的小修正範圍，報價時就會寫清楚。要長期維護或加新功能，可以另外談月費或按次計。

只修一個小問題也可以嗎？

可以。網站跑版、App 編譯不過、Excel 公式壞掉、機器人不回話，這種單點問題也接。

我完全不懂技術，可以找你嗎？

可以。你用自己的話講要解決什麼問題，我會問問題、畫概念圖，把它翻譯成可以做的東西。

大概多久可以做好？

看範圍。小工具、單頁網站、修一個 bug 通常比較快；有登入、有後台、要串金流的系統就要比較久。第一次聊完、範圍確定後，會給你明確的時程。

別人做到一半的專案可以接嗎？

可以。先做一次程式健檢：看懂架構、列出問題、評估修還是重寫比較划算，再決定要不要繼續。

全程遠端嗎？

是，遠端為主，台灣時區。用 LINE 或視訊溝通，需要時用可以點的版本給你看進度。

有不接的案子嗎？

有。違法、侵權、盜版、遊戲外掛、灌量假帳號、未經同意蒐集個資、詐騙與賭博相關，一律不接。

接手舊專案與修復

前一個工程師不見了、程式沒人看得懂、一改就壞？從這裡接。

  • 讀懂沒文件的程式整理成架構圖和說明，讓你知道手上有什麼。
  • 找 bug 根因不只止血，說清楚為什麼壞、怎麼避免再壞。
  • 爛尾專案接手先健檢，評估修還是重寫比較划算。
  • 套件與框架升級版本太舊不支援、有已知漏洞，安全地升上去。
  • 重構功能不變，程式變得好改、好維護。
  • 改寫到新技術例如 jQuery 換 React、PHP 換 Node。
  • 效能問題頁面慢、資料庫查詢慢、記憶體爆掉。
  • 編譯不過 / 跑不起來環境設定、相依套件衝突、建置錯誤。
測試・資安・程式品質

外包交回來的東西能不能信？上線前先檢查。

  • 程式碼審查幫你看別人寫的程式：品質、隱憂、該先修什麼。
  • 安全檢查後門、可疑對外連線、明文密碼、藏在建置流程裡的腳本。
  • 套件漏洞檢查用到的第三方套件有沒有已知漏洞。
  • 自動化測試單元測試、端對端測試，改東西不怕改壞別的。
  • 自動檢查流程（CI）每次改程式自動跑測試、檢查格式。
  • 常見網站漏洞修補SQL 注入、XSS、權限漏洞這類 OWASP 常見問題。
  • 尾款前加密試用系統加密放上網，拿金鑰才能試用，可隨時停權。
  • 版本控制整理Git 分支、紀錄、還原點，出事能退回上一版。
